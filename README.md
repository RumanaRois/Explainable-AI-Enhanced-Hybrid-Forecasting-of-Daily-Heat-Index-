# Explainable-AI-Enhanced-Hybrid-Forecasting-of-Daily-Heat-Index-
Explainable hybrid STL–TBATS–ML forecasting of daily Heat Index for heat early warning at Jessore, Bangladesh. Leakage-free 1–7-day forecasts, conformal prediction intervals, SHAP explanations and Danger-day (HI ≥ 41 °C) warning verification. Code for the manuscript submitted to Advances in Climate Change Research.
